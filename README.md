# MiniEcommerce
Mini e-commerce construido con arquitectura de microservicios (Vue.js + FastAPI + PostgreSQL) como proyecto de aprendizaje. Incluye autenticación OAuth2/JWT, comunicación asíncrona con RabbitMQ, pagos reales con Stripe (modo test), service discovery con Consul, y observabilidad con Prometheus/Loki/Grafana/Jaeger.
